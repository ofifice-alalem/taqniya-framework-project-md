# 🤖 Prompt: Analyze Project Rules (موجّه استيعاب وتحليل قواعد المشروع)

> **الغرض:** يُستخدم لقراءة واستيعاب المتطلبات العامة وقواعد العمل ومفاهيم البيانات قبل البدء في تصميم المخططات أو برمجة المكونات.  
> **حدود الصلاحية:** هذا الموجّه تحليلي بحت لفهم واستيعاب المنطق؛ ولا يقوم بكتابة كود أو إنشاء جداول.

---

## 📝 تعليمات التنفيذ للـ AI Agent

قم بتحليل مواصفات المشروع الشاملة لبناء نموذج ذهني متكامل:

### 1. استيعاب قواعد العمل العامة (`business_rules.md`)
- استخرج قاموس المصطلحات الموحد للمجال (Ubiquitous Domain Glossary).
- حدد الشروط المنطقية غير القابلة للكسر (Business Invariants).
- استخرج مسارات وسير العمليات الحيوية (State Transitions & Workflows).
- استخرج قيود الصلاحيات ومصفوفة التحكم في الوصول (Authorization & RBAC Matrix).

### 2. استيعاب هيكل البيانات والمفاهيم (`data.md`)
- استخرج الكيانات الرئيسية (Entities) والعلاقات المنطقية بينها (1:1, 1:N, N:M).
- حدد استراتيجيات الحفظ، والأرشفة، والـ Soft Deletes، وسجلات التتبع (Audit Logs).
- استخرج متطلبات الاتساق والمعاملات المالية/الحرجة (ACID Constraints).

### 3. استيعاب القيود البصرية والتصميم (`design_rules.md`)
- استخرج هوية النظام البصري، ودعم الاتجاه `dir="rtl"`، والألوان، والخطوط، والمسافات.
- استخرج معايير إمكانية الوصول والتفاعل واستجابة الشاشات (Responsive Breakpoints).

### 4. المخرج المتوقع (Domain & Technical Synthesis)
قدّم ملخصاً تركيبياً شاملاً يجيب عن:
1. ما هو الهدف الأساسي للمشروع وما هي الفئات المستفيدة؟
2. ما هي الكيانات المحورية وكيف تتدفق البيانات بينها؟
3. ما هي أصعب الحالات الحدية (Edge Cases) والشروط الصارمة في العمليات؟
4. تأكيد الجاهزية للانتقال إلى مرحلة تصميم قاعدة البيانات (`03_database/design_database.md`).
