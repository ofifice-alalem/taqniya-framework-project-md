# 🤖 Prompt: Phases Creator (موجّه إنشاء الـ Phases)

> **الغرض:** الموجه الرئيسي لاستخدام الذكاء الاصطناعي في إنشاء مرحلة وظيفية جديدة وتوليد ملفاتها الخمسة القياسية بالبنية المعتمدة.

---

## 📝 التعليمات الموجهة للـ AI Agent

أريد منك إنشاء مرحلة جديدة (Phase) بالمعلومات التالية:
- **اسم المرحلة:** `[أدخل اسم المرحلة، مثال: phase_01_users]`
- **هدف المرحلة:** `[أدخل الهدف الرئيسي]`
- **نطاق العمل:** `[أدخل التفاصيل والوظائف المطلوبة]`

### 🛠️ المطلوب منك توليده:
قم بأنشاء المجلد `PROJECT/MD/phases/<phase_name>/` وتوليد الملفات التالية بداخله مع التفاصيل الكاملة:

1. **`README.md`**: اسم المرحلة، الهدف، نطاق العمل، ما تتضمنه وما لا تتضمنه، الاعتماديات على مراحل أخرى، والحالة.
2. **`backend.md`**: الخدمات والمتحكمات المطلوبة، Logic العمليات، الصلاحيات، وحالات الإدخال والتعديل.
3. **`frontend.md`**: الصفحات والشاشات، العناصر التفاعلية، النماذج والجداول، وحالات Loading / Empty / Error.
4. **`routes.md`**: مسارات API / Web، الطرق المستخدمة (GET, POST, etc.)، Request/Response data والصلاحيات.
5. **`data.md`**: الكيانات، الجداول، الحقول، العلاقات، والقيود التابعة لهذه المرحلة فقط.

التزم بالتركيب القياسي وعدم إضافة قيم التصميم العامة الموجودة في `design_rules.md`.
