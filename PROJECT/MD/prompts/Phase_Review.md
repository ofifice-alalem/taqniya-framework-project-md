# 🤖 Prompt: Phase Review (موجّه مراجعة مرحلة كاملة)

> **الغرض:** مراجعة شاملة لمرحلة بالكامل بعد التنفيذ وقبل الاعتماد النهائي، لتحديد ما تم إنجازه وما لم يتم والمشاكل القائمة.

---

## 📝 التعليمات الموجهة للـ AI Agent

أنت في مرحلة اعتماد الـ Phase التالية: `[أدخل اسم الـ Phase هنا، مثال: phase_00_authentication]`

### 🎯 مطلوب منك تنفيذ الآتي:
1. **قراءة ملفات المرحلة كاملة:**
   - `phases/<phase_name>/README.md`
   - `phases/<phase_name>/backend.md`
   - `phases/<phase_name>/frontend.md`
   - `phases/<phase_name>/routes.md`
   - `phases/<phase_name>/data.md`

2. **فحص ومقارنة الإنجاز (Execution Checklist):**
   - **الـ Backend:** هل جميع الخدمات والمتحكمات المطلوبة تم بناؤها واختبارها؟
   - **الـ Frontend:** هل المكونات والشاشات والحالات مطابقة لمواصفات الواجهة؟
   - **الـ Routes & Data:** هل الـ Endpoints متوفرة وتغييرات الهيكلية مرسلة ومطبقة في قاعدة البيانات؟

3. **تقرير الاعتماد النهائي (Phase Readiness Report):**
   - **نسبة الإنجاز الإجمالية:** (مثلاً: 95%)
   - **ما تم تنفيذه:** قائمة بالمخرجات المكتملة.
   - **ما لم يتم تنفيذه:** المهام المعلقة.
   - **توصية الاعتماد:** (جاهزة للاعتماد / تحتاج تعديلات / غير جاهزة).
