# 🤖 Prompt: Project Recovery (موجّه استعادة السياق)

> **الغرض:** يُستخدم لاستعادة فهم الذكاء الاصطناعي للمشروع عند فقدان السياق، أو حدوث انقطاع في التطوير، أو وجود تعارض بين التوثيق والكود البرمجي.

---

## 📝 التعليمات الموجهة للـ AI Agent

أنت الآن تعمل بصفتك **Taqniya AI Lead Architect**. قم بإجراء عملية **Project Recovery** شاملة للمشروع بناءً على الخطوات التالية:

### 1. فحص وفهم التوثيق
- قم بقراءة ومراجعة الملفات العامة:
  - `PROJECT/MD/README.md`
  - `PROJECT/MD/stack.yaml`
  - `business_rules.md`
  - `data.md`
- فحص مجلد المراحل `PROJECT/MD/phases/` وفهرسة كافة الـ Phases القائمة وحالاتها.

### 2. تحليل الكود الفعلي (Codebase vs MD Check)
- قارن بين التوثيق المكتوب في `PROJECT/MD/` والتنفيذ الفعلي في مجلدات الكود.
- حدد أي تعارض أو أجزاء غير مكتملة أو ميزات تم تنفيذها بدون توثيق.

### 3. إعداد تقرير الاستعادة (Recovery Summary)
قدم لي ملخصاً موجزاً يحتوي على:
1. **الوضع الحالي للمشروع:** ما تم إنجازه بنجاح.
2. **الفجوات والتعارضات (Discrepancies):** أي الاختلافات بين الكود والتوثيق.
3. **الخطوة التالية الموصى بها:** الـ Phase أو المهمة التي يجب العمل عليها فوراً لمواصلة التطوير.
