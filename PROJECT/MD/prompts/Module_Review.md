# 🤖 Prompt: Module Review (موجّه مراجعة جزء وظيفي)

> **الغرض:** يُستخدم لمراجعة Module أو جزء وظيفي محدد للتأكد من اكتمال المتطلبات، وتوافق الكود مع التوثيق، والجودة الفنية.

---

## 📝 التعليمات الموجهة للـ AI Agent

قم بمراجعة الـ Module المسمى: `[أدخل اسم الـ Module هنا]` وفقاً للمعايير التالية:

### 1. مراجعة التوثيق والمطابقة
- تحقق من ملفات الـ Phase التابع لها هذا الـ Module:
  - `backend.md`
  - `frontend.md`
  - `routes.md`
  - `data.md`
- تأكد أن الكود المنفذ يغطي جميع الشروط الواردة في هذه الملفات.

### 2. مراجعة الـ Backend & Database
- التأكد من جودة وتغطية الـ Controllers, Services, Models.
- فحص قواعد Validation والـ Business Rules المعمول بها.

### 3. مراجعة الـ Frontend & Routes
- التأكد من وجود كافة الشاشات وحالات الشاشة (Loading, Error, Empty, Success).
- مطابقة مسارات الـ API بالـ Routes المحددة.

### 4. النتيجة والمخرجات
قم بتقديم تقرير تدقيق يوضح:
- ✅ **نقاط القوة والاكتمال**
- ⚠️ **الملاحظات والنواقص**
- ❌ **الأخطاء والتعارضات التي تتطلب إصلاحاً فورياً**
