# 🤖 Prompt: Execute Phase (موجّه تنفيذ المرحلة عبر محرك التنفيذ المعتمد)

> **الغرض:** يُستخدم لتسليم سياق المرحلة المحلول وقواعدها إلى **محرك التنفيذ المعتمد (Configured Execution Engine)** ليقوم بالتنفيذ البرمجي الكامل.  
> **المبدأ المعماري:** هذا الموجّه لا يفرض أدوات تنفيذ بعينها، بل يُسلم السياق للمحرك المختار في `PROJECT/MD/execution_engine.yaml`.

---

## 📝 تعليمات التنفيذ للـ AI Agent

قم بتجهيز وتسليم سياق المرحلة المحددة: `[أدخل اسم أو مسار مجلد المرحلة]`

### 1. تجهيز السياق الأدنى المحلول للمرحلة (Minimal Resolved Phase Context)
- اجمع وثائق المرحلة المستهدفة من `PROJECT/MD/phases/<target_phase>/`.
- اجمع القواعد والمحددات المرجعية المرتبطة من:
  - بروفايلات التقنية: `FRAMEWORK/06_stack_profiles/`
  - مخطط قاعدة البيانات: `PROJECT/MD/database.md`
  - سياسات الأداء: `PROJECT/MD/frontend_capabilities.yaml`
  - مبادئ النواة: `FRAMEWORK/00_core/*`
  - قواعد الصلاحيات والأمان: `00_core/security_rules.md`

### 2. تسليم المهمة لمحرك التنفيذ المعتمد (Execution Engine Handoff)
- اقرأ المحرك المختار في `PROJECT/MD/execution_engine.yaml` (أو اعتمد `native` إذا لم يُحدد).
- فوّض المحرك للقيام بالتالي:
  - **تخطيط التنفيذ الدقيق والتسلسلي (Task Decomposition).**
  - **تطبيق دورات التطوير الموجه بالاختبارات (TDD Cycles) لكافة منطق العمل الحرج.**
  - **كتابة الكود البرمجي للمتحكمات، النماذج، المستودعات، الخدمات، والواجهات.**
  - **الالتزام الصارم بحدود الطبقات (Layer Boundaries) ومنع التسريب المعماري.**
  - **تصحيح الأخطاء والتنفيذ المتكرر للاختبارات حتى النجاح.**

### 3. إشعار إتمام التنفيذ البرمجي
- عند اكتمال كتابة الكود واجتياز الاختبارات المحلية، يُعلن محرك التنفيذ جاهزية المرحلة.
- يتم الانتقال فوراً إلى مرحلة التدقيق والمراجعة الشاملة عبر موجّه `review_phase.md`.
