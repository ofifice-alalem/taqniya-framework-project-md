## 📱 1. الشاشات والصفحات المطلوبة (Screens & Pages)

### 🖥️ 1. صفحة القائمة الرئيسية (`SampleListPage`)
- **المكونات:**
  - شريط البحث والفلترة حسب الحالة.
  - جدول بيانات لعرض العناصر (DataTable).
  - زر إنشاء عنصر جديد (فتح Modal / الانتقال لصفحة الإنشاء).
  - زر الإجراءات لكل صف (تعديل، عرض، حذف).

### 📝 2. نموذج الإنشاء والتعديل (`SampleFormModal`)
- **الحقول:**
  - حقل إدخال نصي لـ `name`.
  - قائمة منسدلة لاختيار `status`.
  - قائمة منسدلة لاختيار `category_id`.
- **الإجراءات:**
  - زر حفظ (Submit) مع مؤشر تحكم أثناء التحميل.
  - زر إلغاء (Cancel).

---

## 🔄 2. حالات الشاشة والتفاعل (UI States)

| الحالة | التوصيف |
| :--- | :--- |
| **Loading State** | عرض مؤشر التحميل Skeleton Loader في قائمة البيانات |
| **Empty State** | عرض رسالة "لا توجد بيانات حالياً" مع زر لإضافة أول عنصر |
| **Error State** | عرض تنبيه أحمر يوضح سبب الخطأ مع زر إعادة المحاولة (Retry) |
| **Success State** | عرض التنبيه الأخضر Toast Notification عند نجاح الإضافة/التعديل |

---

## ⚡ 3. إجراءات التفاعل والمؤشرات (Interactions)
- **النموذج:** فحص وتدقيق الحقول (Client-side validation) فور الخروج من الحقل (On blur).
- **التأكيد على الحذف:** عرض نافذة تأكيد (Confirmation Modal) قبل تنفيذ عملية الحذف.
