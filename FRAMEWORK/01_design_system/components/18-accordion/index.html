18. القوائم الأكورديون (Accordion)

Smooth Expand · Multi-Panel

أكورديون المواصفات والمعايير الهندسية (System Accordion)

قوائم مطوية انسيابية لعرض الإجابات والمواصفات المعمارية الدقيقة

تعتمد منظومة تقنية على ملف تصميمي مركزي واحد كمستند وحيد وموثوق (SSoT). يمنع كتابة أي تنسيقات CSS عشوائية، ويتم استيراد كافة المتغيرات والتدرجات من ملف `css/style.css` حصراً.

Strict Rule: Design Tokens must match CSS Custom Properties across Light/Dark modes.

يتضمن النظام 5 قياسات أساسية تبدأ من `sm: 640px`، مروراً بـ `md: 768px`، `lg: 1024px`، `xl: 1280px`، وصولاً إلى الشاشات العريضة `2xl: 1536px` مع دعم حقيقي لتنسيق RTL بالكامل.

يتم فرض التحقق الثنائي عبر OTP، وتشفير الاتصال ببروتوكول TLS 1.3 مع تطبيق مصفوفة صلاحيات تفصيلية (Read, Write, Deploy, Audit Logs).
