# Prompt: Module Review

> **Purpose:** Review a specific functional module against its phase specifications and engineering standards.

---

## Instructions for AI Agent

Review the target module: `[MODULE_NAME]`

1. **Verify Specifications:** Check `backend.md`, `frontend.md`, `routes.md`, `data.md` in the target phase.
2. **Audit Code Quality:** Verify boundary separation, validation rules, strict typing, and test coverage.
3. **Generate Audit Report:**

   - ⚠️ Observations & minor gaps
   - ❌ Critical bugs or discrepancies requiring immediate fix
