### 2. توليد وكتابة الـ Migrations
- أنشئ ملفات الـ Migration وفق التسلسل الزمني المنطقي للعلاقات (الجداول الأب أولاً ثم الجداول التابعة).

- إذا لاحظت أثناء كتابة التهجير أن هناك حقلاً ناقصاً أو حاجة لجدول جديد:
  - 🛑 **توقف فوراً عن التنفيذ (STOP).**

  - أبلغ المطور بالنقص واقترح تحديث `PROJECT/MD/database.md` أولاً عبر موجّه `design_database.md`.

### 4. تطبيق واختبار الـ Migrations
- شغّل أمر تنفيذ التهجيرات الخاص بإطار العمل (مثال: `php artisan migrate` أو أدوات إدارة الـ DB).
