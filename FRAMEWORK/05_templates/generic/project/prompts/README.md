# 🤖 Taqniya Project Prompts Directory (دليل موجّهات المشروع)

> **الغرض:** يحتوي هذا المجلد على الموجّهات المعيارية الأربعة لإدارة دورة حياة المشروع الكاملة تحت مظلة **Taqniya AI Development Framework**.

---

## 🌳 هيكلية وتصنيف الموجّهات

```text
prompts/
│
├── README.md                              # دليل وفهرس الموجّهات
│
├── 01_project_initialization/             # المرحلة الأولى: تهيئة المشروع
│   ├── initialize_project.md              # تهيئة التقنيات وسياسات الواجهة ومحرك التنفيذ
│   └── review_project_configuration.md    # مراجعة وتدقيق الإعدادات الثلاثية
│
├── 02_project_analysis/                   # المرحلة الثانية: استيعاب وتحليل المشروع
│   └── analyze_project_rules.md           # تحليل قواعد العمل، الكيانات، والقيود البصرية
│
├── 03_database/                           # المرحلة الثالثة: قاعدة البيانات
│   ├── design_database.md                 # تصميم وتوثيق المخطط التفصيلي (database.md)
│   └── implement_database.md              # تنفيذ وتطبيق التهجيرات (Migrations) الصارمة
│
└── 04_phases/                             # المرحلة الرابعة: تطوير المراحل الوظيفية
    ├── analyze_phase.md                   # تحليل نطاق ومخاطر واختبارات المرحلة
    ├── execute_phase.md                   # تفويض التنفيذ لمحرك التنفيذ المعتمد
    └── review_phase.md                    # مراجعة واجتياز بوابات التحقق الثمانية
```

---

## 🔄 مصفوفة استخدام الموجّهات

| المرحلة | الموجّه | التوقيت | الناتج المتوقع |
| :--- | :--- | :--- | :--- |
| **01. التهيئة** | `initialize_project.md` | عند بداية المشروع | `stack.yaml`, `frontend_capabilities.yaml`, `execution_engine.yaml` |
| | `review_project_configuration.md` | بعد التهيئة | تقرير اتساق الإعدادات |
| **02. التحليل** | `analyze_project_rules.md` | قبل تصميم الـ DB | استيعاب شامل لقواعد العمل والنظام |
| **03. قاعدة البيانات** | `design_database.md` | بعد تحليل القواعد | مخطط هندسي معتمد في `database.md` |
| | `implement_database.md` | بعد اعتماد المخطط | ملفات تهجير منفذة ومختبرة بنسبة 100% |
| **04. المراحل الوظيفية** | `analyze_phase.md` | قبل كتابة كود المرحلة | تقرير نطاق ومخاطر ومعايير DoD |
| | `execute_phase.md` | أثناء التطوير | كود وميزات برمجية منفذة من المحرك المعتمد |
| | `review_phase.md` | بعد التنفيذ | تقرير اجتياز بوابات التحقق واعتماد المرحلة |
