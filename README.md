Taqniya Framework & Project MD Integration Reference

هذا المستودع هو المرجع العملي الذي يوضح كيفية استخدام Taqniya AI Development Framework مع توثيق المشروع (Project MD) للحصول على أفضل نتائج ممكنة أثناء تطوير المشاريع باستخدام وكلاء الذكاء الاصطناعي.

يحتوي المستودع على مكونين مستقلين:

FRAMEWORK/
يحتوي على ملفات وقواعد Taqniya AI Development Framework نفسها، بما في ذلك القواعد الهندسية، بروتوكولات عمل الـ AI، الاختبارات، الـ workflows، القوالب، والبروفايلات التقنية.
PROJECT_MD/
يحدد الطريقة المقترحة لتنظيم وتوثيق معلومات المشروع الذي سيعمل عليه الـ Framework، بما في ذلك معلومات المشروع العامة، التقنيات المستخدمة، قواعد العمل، البيانات، التصميم، ومراحل التنفيذ مع تفاصيل الـ Backend والـ Frontend والـ Routes والـ Data.

الهدف من المستودع هو توفير مرجع موحد يوضح:

Taqniya Framework
        │
        │ governs how the AI works
        ▼
    Project MD
        │
        │ describes what the project is
        ▼
   AI Agent / Host
        │
        ▼
 Project Implementation

Taqniya Framework يحدد كيف يجب أن يعمل الوكيل هندسياً، بينما Project MD يصف ما هو المشروع وما هي متطلباته وقواعده وبياناته ومراحله.

وبالتالي فإن هذا المستودع لا يعتبر PROJECT_MD جزءاً من الـ Framework، وإنما يجمع الاثنين في مكان واحد كمرجع يوضح أفضل طريقة لتهيئة المشروع وتشغيل Taqniya عليه.
